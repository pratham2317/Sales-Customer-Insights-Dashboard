# Sales & Customer Insights Dashboard

## Portfolio Project
**Tools:** SQL, Advanced Excel, Power BI, Python/Pandas

## Objective
Build a B2B sales analytics solution that helps management understand revenue, profitability, customer segments, lead sources, regional performance and sales-team effectiveness.

## Dataset
The dataset contains **1,500 synthetic B2B sales/opportunity records** covering 2025–2026.

It includes:
- Orders and dates
- Customers and customer segments
- Cities and regions
- Product categories
- Lead channels
- Sales representatives
- Won/Lost/Open status
- Quantity, price and discounts
- Revenue, cost and profit
- Sales-cycle duration
- New vs existing customer classification

**Data disclaimer:** This is synthetic portfolio data, not real Texzone data and not confidential company information.

## Business KPIs
The dashboard is designed around:
- Total Revenue
- Total Profit
- Profit Margin
- Won Orders
- Unique Customers
- Average Order Value
- Conversion Rate

## Key business questions
1. Which product categories generate the highest revenue?
2. Which regions contribute the most sales?
3. Which lead channels have the best conversion rates?
4. Which customer segments have the highest value?
5. Which customers are high-value accounts?
6. Which sales representatives generate the most revenue?
7. Where are opportunities to improve the sales cycle?
